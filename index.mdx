ASIMP (Ansible System Integrity Management Platform) is a host-based, automated security hardening and compliance auditing framework powered entirely by Ansible. It implements a strict **Measure → Harden → Re-Measure** pipeline that gives you instant, quantified visibility into your system's security posture before and after hardening policies are applied. ASIMP supports Ubuntu, Debian, RHEL, CentOS, Rocky Linux, and AlmaLinux — covering the full range of modern enterprise Linux distributions.

## Get Started in 3 Steps

<Steps>
  <Step title="Install Prerequisites">
    Make sure Python 3.8+ is available, then create a virtual environment and install ASIMP's Python dependencies:

    ```bash
    python3 -m venv /tmp/venv
    source /tmp/venv/bin/activate
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Install Ansible Galaxy Roles">
    Download the required external Ansible roles — including SSH hardening, OS hardening, Lynis, and NTP synchronisation:

    ```bash
    ansible-galaxy install -r requirements.yml
    ```
  </Step>
  <Step title="Run Your First Hardening Playbook">
    Harden and audit the local machine in a single command. ASIMP will scan before hardening, apply all policies, then re-scan and print a comparative scorecard:

    ```bash
    ansible-playbook --connection=local -b -K play-localhost.yml
    ```
  </Step>
</Steps>
